# Analogical Transfer — Example Session (Brief Mode)

## Command

```
/libertee:analogical-transfer "How can we reduce knowledge silos between teams?" --brief
```

## What Happens

✋ **Facilitator** frames the move:

> *We'll leave your industry and look at how this structural problem is solved elsewhere — far elsewhere. The point isn't a metaphor, it's an operating principle.*

### 🧬 Abstract Structure

A network of partially-overlapping nodes hoards locally-useful information that would be more valuable globally; the cost of sharing is borne by the holder, the benefit accrues to others.
**Type:** Distribution — under-incentivized publication of locally-held resources.

### 🌍 Cross-Domain Map

**Domain: Honeybee waggle dance.**
**Mechanism:** Returning foragers perform a structured dance encoding direction and distance to nectar; the dance is involuntary-by-physiology and broadcast publicly. Hive members select which signals to follow based on resonance; bad sources fade because no one follows.
**Operating principle:** Make sharing structural and low-cost; let receivers select rather than gatekeep.

**Domain: Open-source upstreaming culture.**
**Mechanism:** Companies modifying open-source dependencies upstream changes back because *not* upstreaming creates a maintenance debt that grows over time; the upstream itself becomes a public commons that everyone draws from.
**Operating principle:** Make hoarding *more expensive* than sharing through structural friction (maintenance debt), not through exhortation.

### 🔄 Transfer

- **Make sharing structural / low-cost** — Direct transfer. Build a shared substrate (writing-by-default, public Slack channels, weekly five-line "what I'm working on" posts) so sharing happens as a side-effect of work, not as additional work.
- **Make hoarding more expensive than sharing** — Adapted. Hard to mimic open-source's natural maintenance debt directly; but tying team performance to *visible* contribution to shared resources creates an analogous cost.

### 🎯 Principles to Apply

- **Sharing as side-effect, not extra effort** — design tooling so the shared trace is created automatically.
- **Asymmetric cost** — make the cost of *not* sharing feel real (project velocity, team reputation), not just exhorted.

**💡 The Frame Shift:** The problem isn't "people don't want to share" — it's "the cost structure rewards hoarding." Both analog domains tell the same story: change the cost structure, the behavior follows.
