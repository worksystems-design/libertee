# Futures Cone — Structural Tests

## Scenario 1: Default (Binary) mode

**Command:** `/libertee:futures-cone "Wie wird Wissensarbeit in 5 Jahren aussehen?"`

**Required:**
- [ ] Section header `## ✋  Setting the Question` (or matching localized equivalent)
- [ ] Facilitator opening explicitly states a time horizon (in this case: 5 years)
- [ ] Section header `## 🔭  Scenarios`
- [ ] **Exactly four** zone-labeled scenarios: Probable, Plausible, Possible, Preposterous
- [ ] Each scenario has: name, 2-3 sentence description, named driver
- [ ] The Preposterous scenario is genuinely edge-of-imagination, not "slightly bolder than plausible" — if all four scenarios feel like variants of the same trajectory, the agent failed
- [ ] Section header `## 📡  Indicators`
- [ ] Per scenario: at least 2-3 concrete, observable indicators
- [ ] Indicators are not vague ("more discussion of X") but concrete (publication trends, regulatory filings, measurable inflections)
- [ ] Each indicator marked: leading vs. confirming, already present vs. not yet visible
- [ ] Section header `## 🛡️  Robustness`
- [ ] Section: "Robust across all four zones" — at least 1 choice
- [ ] Section: "Brittle in [zones]" — at least 1 choice with named failure zones
- [ ] Section: "Leverage moves" — at least 1 optionality / hedge / reversibility choice
- [ ] Facilitator synthesis: `🎯  The Robust Portfolio`, `🚦  Indicators to Watch`, `⚠️  Brittle Defaults`, `💡  The Hidden Future`
- [ ] The recommended portfolio names 2-3 choices, not 1 — robustness is portfolio, not single bet

## Scenario 2: Brief mode

**Command:** `/libertee:futures-cone "Sollten wir auf eine async-only Kultur umstellen?" --brief`

**Required:**
- [ ] Same four phase headers (✋, 🔭, 📡, 🛡️)
- [ ] Four scenarios still present (zone count is non-negotiable)
- [ ] Each scenario in 1-2 sentences
- [ ] 1 indicator per scenario (not 2-3)
- [ ] Robustness: 1 robust choice, 1 brittle choice; no leverage section
- [ ] Synthesis: portfolio in 1-2 lines

## Scenario 3: Polarity mode

**Command:** `/libertee:futures-cone "Wird unsere Branche eher konsolidieren oder fragmentieren?" --polarity`

**Required:**
- [ ] Phase headers as in Scenario 1 through Step 4
- [ ] Synthesis identifies that scenarios across zones embody an interdependent polarity (in this case: consolidation ↔ fragmentation)
- [ ] Polarity named explicitly with both values (form `X ↔ Y`)
- [ ] Synthesis describes a stance that holds the tension across the time horizon, not a stance that picks a zone
- [ ] At least one recommendation involves "holding the tension gracefully" rather than "preparing for zone X"

## Scenario 4: Join scenarios

**Command:** `/libertee:futures-cone "Wie verändert sich der B2B-Vertrieb durch AI-Agents?" --join scenarios`

**Required:**
- [ ] After `## ✋  Setting the Question`, facilitator addresses USER directly with the four-zone scenario brief
- [ ] Brief explicitly names the four zones with definitions, mentions taking preposterous seriously
- [ ] No `## 🔭  Scenarios` section auto-generated by an AI agent — that's now waiting on the user
- [ ] Once user input arrives: AI Scenario Cartographer runs Indicators and Robustness passes normally
- [ ] Synthesis runs based on user's scenarios + AI's indicators and robustness

## Notes for the runner

The hardest test in Scenario 1 is the **Preposterous zone**. If it reads as "a slightly more aggressive version of plausible", the agent didn't push. The Preposterous scenario should feel uncomfortable to the team — not impossible, but at the edge of what they can accept as worth taking seriously. If you spot this, sharpen the agent file's "Preposterous means edge-of-imagination, not impossible" instruction.

The **observable indicators** test in Step 3 is also a frequent failure point. "Increased uncertainty" is not an indicator. "Top-3 enterprise SaaS vendors all announce platform-shift roadmaps within 6 months" is.

The **portfolio not single-bet** test in Robustness is the most important downstream check. If the synthesis comes back with "do X" — single decision — it's collapsed back into forecasting. The cone's value is in surfacing 2-3 choices that handle different zones differently.
